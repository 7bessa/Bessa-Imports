# Bessa Imports

Loja online da Bessa Imports. O site é estático e carrega o catálogo da planilha Google publicada. Os pedidos são finalizados pelo WhatsApp.

Site: https://7bessa.github.io/Bessa-Imports/

## Painel administrativo

A configuração para cadastrar peças fica em [PAINEL-ADMIN.md](PAINEL-ADMIN.md). A implantação do Apps Script precisa ser feita na conta Google proprietária da planilha.
